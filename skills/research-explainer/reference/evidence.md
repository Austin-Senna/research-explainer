# Evidence calibration

How much weight each authoring rule carries, and which popular claims have nothing under them.

| Grade | Meaning |
|---|---|
| **[A]** | Multiple independent meta-analyses agree, no strong contrary finding |
| **[B]** | One meta-analysis or several controlled studies, with known caveats |
| **[C]** | Convergent practice across best-in-class exemplars; no controlled test |
| **[U]** | Learned from watching this tool fail in use. No literature — a real reader got stuck at a specific, reproducible place, and the rule is what fixed it. Weaker than a meta-analysis about learning in general, stronger than one about a different medium |
| **[D]** | Contested — credible findings point both ways. Pick deliberately, don't over-claim |

## Do not build on these

| Claim | Status |
|---|---|
| "Chunk into N-minute pieces" | Folk wisdom. Segment size has never been tested as a moderator |
| "6-minute videos" | A watch-time correlation, n=4 courses, explicitly disclaimed by its own authors as evidence about learning |
| "7±2 items" | Wrong memory system, wrong task, wrong number. It was serial recall of unrelated items held in the head; a visible menu is recognition |
| "Flatter is always better" | Mis-citation. Larson & Czerwinski found a *medium* breadth/depth condition beat the broadest shallow one |
| "Pagination aids comprehension" | Underpowered pre-2012 studies with marginal p-values; the well-powered 2025 replication is p = 0.93 |
| Progressive disclosure "30–50% faster" | Unsourced agency-blog numbers. Nielsen's own article contains no data at all |
| Mayer's effect sizes | Unweighted medians of his own lab on experimenter-built tests, ~2–5× independent estimates (which converge near g ≈ 0.37) |
| Advance organizers | d ≈ 0.21, badly-defined construct, quietly dropped from Hattie's updated list |
| Concept maps vs. outlines | g = 0.278 against an outline; **in hypertext, g = 0.017, n.s.** |
| Hypercorrection on conceptual content | Contested — one study got the reverse (35.8% vs 61.0%). May be fact-retrieval only |
| Question format rankings | Three meta-analyses, three mutually incompatible orderings |
| Quiz dosage | 1 > many / n.s. / monotonic, depending on who you read. Probably a spacing confound |
| Bloom's 2-sigma | Does not replicate. Modern tutoring meta-analyses land ~d = 0.36 |
| ICAP ordering | A *hypothesis* supported largely by post-hoc reinterpretation; Chi's own abstract hedges. Published critique in 2023 |
| KWL | No meta-analysis in 40 years. Its citation count reflects adoption, not validation |
| "Knowledge shields" | Unverifiable — a theoretical construct with no empirical test found |
| Expertise reversal itself | I² = 88–91%. Two meta-analyses found prior knowledge was *not* a moderator of design-principle effects |
| "Pretesting demotivates" | No direct evidence in either direction. Don't let anyone claim it |
| Gamification novelty decay | Theoretically motivated, not established; two meta-analyses found the opposite duration gradient |

## The one-line version

Wherever a headline effect size appears, **the quality-adjusted figure is roughly half**.
Refutation text is g = 0.41 overall but **0.11, non-significant, in unpublished theses**.
Conceptual-change strategies are g = 1.10 but 0.64 in true experiments and 0.71 after
trim-and-fill. Mayer's multimedia principles are d ≈ 0.7–1.9 in his own tables but g ≈ 0.37
in independent pooling.

**The direction of nearly every finding survives. The magnitudes mostly do not.**
